# acta-license

Lizenz- und Aktivierungsprüfung für Acta Feature-Ringe.

Normativitätsklasse: **Erweiterung `[E]`** (Ring 4, `experimental`; §6.9, `capabilities.toml`).

## Rolle in einem Satz
`acta-license` prüft kryptografische Lizenzschlüssel zur Freischaltung optionaler Enterprise- und Feature-Ringe.

## Ring, Klasse & Reifegrad
- **Ring:** Ring 4 (Erweiterung)
- **Klasse:** Erweiterung `[E]`
- **Reifegrad:** `experimental`
- **Erlaubte Abhängigkeiten (`may_use` Obergrenze):** `acta-types`, `acta-crypto`, `acta-ports` (Spec §6.9, `capabilities.toml`)
